# Lead Generation Widget

An embeddable widget for capturing and qualifying leads, built as part of a Frontend AI Engineering internship capstone.

## Project Overview

The **Lead Generation Widget** is an embeddable frontend component that businesses can drop into their website to capture and qualify visitor leads through a simple, guided form — reducing manual follow-up and improving the quality of leads that reach sales teams.

**Who it's for:** small businesses and marketing teams who want a lightweight, easy-to-embed lead capture tool without building one from scratch.

**Current focus:** the first feature being built is a settings form with validation — this establishes the patterns (form handling, validation, component structure) the rest of the widget will build on.

**Run it locally:**
```bash
git clone https://github.com/olanrewajudon/frontend-ai-capstone.git
cd frontend-ai-capstone
npm install
npm run dev
```
